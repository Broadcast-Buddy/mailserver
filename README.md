# 📬 Broadcast Buddy — Dedicated Mailserver (`mail.broadcastbuddy.app`)

This directory contains the production Docker configuration for hosting your own secure, authenticated mailserver using **`docker-mailserver`** for **`broadcastbuddy.app`**.

---

## 1. Required DNS Records

In your domain registrar / DNS manager (Cloudflare, Namecheap, GoDaddy, etc.):

| Type | Name / Host | Target / Value | Priority | Description |
|---|---|---|---|---|
| **A Record** | `mail` | `YOUR_VM_PUBLIC_IP` | - | Points mail subdomain to VM |
| **MX Record** | `@` | `mail.broadcastbuddy.app` | `10` | Routes incoming domain mail |
| **TXT Record** | `@` | `v=spf1 mx ~all` | - | SPF Authentication Record |
| **TXT Record** | `_dmarc` | `v=DMARC1; p=none; sp=none; rua=mailto:admin@broadcastbuddy.app` | - | DMARC Policy Record |
| **TXT Record** | `mail._domainkey` | *(Generated by `./setup.sh dkim`)* | - | DKIM Signature Record |

---

## 2. Firewall Port Configuration (on VM)

Ensure the required mail ports are allowed:

```bash
sudo ufw allow 25/tcp    # SMTP (incoming)
sudo ufw allow 465/tcp   # SMTPS (outgoing TLS)
sudo ufw allow 587/tcp   # SMTP Submission (STARTTLS)
sudo ufw allow 993/tcp   # IMAPS (secure email client sync)
sudo ufw reload
```

---

## 3. Deployment & Account Setup

### Step 1: Start the Mail Server
```bash
cd /var/www/broadcast-buddy/mailserver
chmod +x *.sh
sudo docker-compose up -d
```

### Step 2: Create Email Accounts
```bash
./setup.sh add support@broadcastbuddy.app "YourSecurePassword123!"
./setup.sh add admin@broadcastbuddy.app "YourSecurePassword123!"
```

### Step 3: Generate DKIM Keys
```bash
./setup.sh dkim
```
Copy the generated key from `./mail-config/opendkim/keys/broadcastbuddy.app/mail.txt` and paste it into your DNS manager as a `TXT` record with name `mail._domainkey`.

---

## 4. Updates & Management

```bash
# Update mailserver image
./update.sh

# View live logs
./setup.sh logs

# List existing accounts
./setup.sh list
```
